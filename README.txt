GMod Loading — fonds compatibles navigateur GMod (CEF)

Mise en ligne : importer le CONTENU de ce dossier à la racine du dépôt GitHub zoedcls/gmod-loading.
Laisser index.html, style.css, script.js et assets/ au même niveau.
Les images de fond sont assets/backgrounds/bg-1.png et bg-2.png ; GIF assets/spinner.gif.
Les deux fonds sont désormais des balises img HTML, et le script bascule leur opacité toutes les 7 secondes.
Ne pas modifier les chemins d’image sans mettre aussi index.html à jour.
Vérifier l’adresse dans un navigateur ; sur HOPELA, sv_loadingurl peut pointer vers https://zoedcls.github.io/gmod-loading/?v=4
Attention : l'indicateur Steam Workshop visible en bas à droite du chargement est affiché par le jeu, et ne dépend pas de cette page HTML.
